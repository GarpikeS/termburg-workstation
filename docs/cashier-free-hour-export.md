# Ежедневная выгрузка бесплатных часов

Сервис формирует защищённый CSV со всеми кодами бесплатного часа за выбранный день. Файл открывается в Excel и подходит как промежуточный формат для загрузки в кассовую систему.

## Настройка на сервере

В `/etc/termliny-game/feedback.env` должен быть отдельный длинный секрет:

```env
CASHIER_EXPORT_TOKEN=replace-with-a-long-random-secret
```

После изменения переменной нужно перезапустить `termliny-feedback.service`.

## Получение файла

```powershell
$env:TERMBURG_CASHIER_TOKEN = 'секрет-из-настроек-сервера'
$headers = @{ Authorization = "Bearer $env:TERMBURG_CASHIER_TOKEN" }
Invoke-WebRequest `
  -Uri 'https://tbgame.ru/api/admin/rewards/free-hour/export?date=2026-08-13&city=Москва' `
  -Headers $headers `
  -OutFile 'termburg-free-hour-2026-08-13-moscow.csv'
```

Параметры:

- `date=YYYY-MM-DD` — локальная дата выбранного Термбурга;
- `city=Москва` или `city=Зеленогорск` — необязательный фильтр;
- без `city` выгружаются оба города.

Колонки CSV: код, город, имя, телефон, дата покупки, срок действия и статус (`active`, `expired` или `redeemed`). Секрет нельзя размещать во фронтенде или передавать кассирам в открытом виде; выгрузку должен выполнять ответственный сотрудник или защищённая автоматизация.

Для прямого импорта в «Дельфин» понадобится образец требуемого CSV либо описание его API. Текущая выгрузка сохраняет все нужные исходные поля и не привязана к внутреннему формату конкретной кассовой системы.
