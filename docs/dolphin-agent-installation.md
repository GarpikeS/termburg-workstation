# Установка «Термбург Dolphin» на компьютер с Dolphin

## Что делает сотрудник

1. Скачивает выданный установщик `Termburg-Dolphin-Setup-1.1.0.exe` именно на компьютер, где запущен Dolphin.
2. Дважды нажимает на файл и подтверждает установку Windows.
3. Ждёт появления окна «Термбург · Dolphin».
4. Нажимает «Проверить сейчас» и оставляет программу запущенной. Закрытие окна сворачивает её рядом с часами.
5. Присылает разработчику только фотографию статуса на экране. Ключи, пароли и выгрузки пересылать не нужно.

## Как понять результат

- «Dolphin найден» — локальный API доступен, формат данных отправлен на сервер для проверки; билеты пока не погашаются автоматически.
- «Автопогашение работает» — схема уже проверена и сервер включил погашение.
- «Локальный API Dolphin отклонил API-ключ» — на этом компьютере Dolphin использует другой ключ.
- «Локальный API Dolphin не нашёл метод штрихкодов» — версия Dolphin использует другой адрес метода.
- «Нет связи с локальным API Dolphin» — Dolphin не запущен, API выключен или доступен на другом локальном адресе.

## Важно

- Установщик одноразовый и предназначен для одного компьютера.
- Публичный порт открывать не требуется.
- Приложение запускается вместе с Windows и проверяет Dolphin каждые 5 минут.
- Папка «Загрузки» остаётся резервным способом: если туда положить выгрузку Dolphin, агент также её обработает.
