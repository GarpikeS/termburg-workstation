# Телевизионная сетка Workstation 1.1.23

## Причины регрессии

Часы использовали background-clip: text на отдельных цифрах вместе с line-height: .88. Фон текстовой маски не покрывал весь глиф, поэтому нижняя часть цифр выглядела срезанной. Уменьшение/перемещение блока не устраняло причину.

Телевизионные строки наследовали несколько слоёв правил общих карточек, печати и container overrides. Цена дополнительно смещалась translateY и не имела гарантированной области внутри ряда. Проверка с одним событием не выявляла переполнение плотного дня.

## Исправление

- Один изолированный телевизионный компонент и набор стилей, без общих карточек редактора/печати.
- Обычный одноцветный табличный шрифт часов, line-height больше 1; без текстовой маски.
- Три непересекающиеся ячейки шапки: заголовок, логотип, часы.
- Шесть равномерных рядов по два события в горизонтальной ориентации / девять рядов в вертикальной.
- Две строки названия, отдельная строка места и цены, без трансформации ценника.
- Размеры считаются от доступной высоты/ширины; vw/vh fallback для браузеров без container units.
- Полноэкранная кнопка находится за пределами области событий и исчезает после входа в полный экран.
- Завершённые события скрываются; текущие длинные мероприятия остаются; после завершения дня показывается следующий день.

## Проверено

Production frontend build, локальный mock из frontend/tests/fixtures/tvSchedule.mjs. На один комплекс: 13 событий, из них 12 остаются в 12:40, есть двухстрочные названия, платные/бесплатные позиции и текущее мероприятие 10:00–21:00. Это тестовые данные, они не публикуются ни на сайт, ни в рабочее расписание.

Read-only DOM probe проверял: шапку, содержимое каждого ряда, отсутствие пересечения названия/метаданных и места/цены, последнюю строку, обрезание длинных названий, кнопку полного экрана и размер документа. Скриншоты отдельно просмотрены. Проверены вход в полный экран и исчезновение кнопки.

В этой среде проверка выполнялась в Chromium, не на физическом телевизоре комплекса. После обновления требуется контрольный снимок с самого ТВ.

## Воспроизведение

1. npm --prefix frontend run build
2. node scripts/serve-tv-layout-qa.mjs
3. Открыть http://127.0.0.1:4189/schedule/screen/2/landscape либо /portrait через браузерный инструмент.
4. Для Москвы: /schedule/screen/1/landscape?qaNow=2026-10-01T09:40:00Z.
5. Сменить размеры, проверить последний ряд и часы; закрыть тестовую вкладку и остановить локальный QA server.

QA server слушает только localhost; не читает рабочие файлы доступа, расписания или Dolphin.

## Инварианты релиза

Публичное обновление не содержит credentials или enrollment tokens. Алгоритмы авторизации, изоляция комплексов, WordPress/site-sync, часовые пояса и Dolphin не изменены. Тест авторизации теперь ожидает ready перед setup, как это уже делает сервер: устраняется гонка только тестового запуска.
