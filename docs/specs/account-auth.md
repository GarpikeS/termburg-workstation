# Профиль Термбурга: вход по телефону и паролю

Актуально с 15 августа 2026 года.

## Задача

- регистрация по российскому номеру, паролю, имени и указанному пользователем городу;
- повторный вход по телефону и паролю;
- скрытые служебные игровые профили могут входить по выданному логину без отдельной панели;
- синхронизация прогресса между устройствами;
- защита от перебора паролей, массовой регистрации и подмены валюты.

Гостевая игра продолжает работать без профиля, но её прогресс привязан к одному браузеру.

## Хранение данных

Телефон нормализуется до `+7XXXXXXXXXX`. В профиле хранятся HMAC телефона и последние четыре цифры для отображения. Полный номер в базе профилей не хранится. Служебный игровой профиль хранит отдельный логин и никак не связан с редактором расписания.

Пароль:

- от 4 до 128 символов;
- не обрезается и не преобразуется;
- хранится только как результат `scrypt` с индивидуальной солью;
- никогда не возвращается клиенту и не пишется в журналы.

IP и идентификатор устройства хешируются перед записью.

## API

### `GET /api/auth/config`

Возвращает готовность входа, метод `password` и минимальную длину пароля.

### `POST /api/auth/register`

```json
{
  "phone": "+7 999 123-45-67",
  "password": "example-only-password",
  "name": "Анна",
  "city": "Казань",
  "timeZone": "Europe/Moscow",
  "consent": true,
  "consentVersion": "account-2026-08-15",
  "deviceId": "browser-device-id",
  "progress": {}
}
```

Создаёт профиль, переносит в него безопасно нормализованный гостевой прогресс и сразу выдаёт сессию. Поле `city` принимает любой непустой город длиной до 40 символов. Часовой пояс браузера хранится отдельно и используется для корректной смены игрового дня; старые клиенты без `timeZone` продолжают работать с часовым поясом известного города или Москвы.

### `POST /api/auth/login`

```json
{
  "identifier": "+7 999 123-45-67",
  "password": "example-only-password",
  "deviceId": "browser-device-id"
}
```

Поле `identifier` принимает телефон либо заранее выданный служебный логин. Обычная регистрация по-прежнему создаётся только по телефону.

При ошибке ответ одинаковый для неизвестного телефона/логина и неверного пароля. После 5 ошибок для идентификатора или 20 ошибок для IP в окне 15 минут вход временно блокируется.

### `GET /api/auth/me`, `POST /api/auth/logout`

Проверяют и завершают 30-дневную сессию. Cookie: `HttpOnly`, `Secure`, `SameSite=Lax`.

### `PUT /api/account/progress`

Сохраняет прогресс. Начисления ограничены 30 термокоинами на игру и 120 суммарно за день. Коды наград принимаются только из серверного журнала.

## Ограничения

- не более 2 новых профилей на одном устройстве за 30 дней;
- не более 5 активных сессий на профиль;
- запросы изменения защищены проверкой `Origin`.

Секрет `AUTH_SECRET` задаётся только в `/etc/termliny-game/feedback.env` и не попадает в репозиторий или фронтенд.
