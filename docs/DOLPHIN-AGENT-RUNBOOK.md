# Термбург Dolphin: установка и работа

## Что делает EXE

Агент проверяет папку выгрузок Dolphin при запуске и каждые 5 минут. Из `.xls`, `.xlsx`, `.csv`, `.tsv` и `.json` он читает только:

- `Номер`;
- `Основание для льготы`;
- `Время входа`.

Строка попадает на сервер, только если код точно соответствует `TB-XXXXXXXX` и заполнено `Время входа`. Имя, телефон и остальные поля не читаются и не отправляются.

## Первый запуск

1. Запустите `Termburg-Dolphin-Setup-*.exe`.
2. Нажмите установку и дождитесь запуска программы.
3. Дождитесь зелёного статуса `Всё работает`.

Код, папку и автозапуск настраивать не нужно: программа сама подключится, будет смотреть папку `Загрузки`, останется в трее и запустится вместе с Windows. Кнопка `Выбрать` нужна только если Dolphin сохраняет выгрузки в другое место.

## Важно

- Для старых `.xls` на компьютере нужен Microsoft Excel. Без Excel используйте CSV-выгрузку.
- Один установщик активирует один рабочий компьютер. Для другого компьютера выпускается новый установщик.
- Неизвестный серверу код остаётся в очереди до 7 дней.
- Повторная выгрузка не создаёт дубли.
- Кнопка `Перечитать все файлы` нужна только для диагностики: сервер всё равно не погасит билет дважды.
