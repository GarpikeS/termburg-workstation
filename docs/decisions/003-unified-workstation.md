# ADR-003: отдельный объединённый EXE для расписания и Dolphin

- Статус: принято
- Дата: 2026-09-01

## Контекст

На рабочем компьютере нужны две постоянные функции: локальный сервер/редактор расписания и фоновое получение входов из Dolphin. У сотрудников нет технического специалиста, поэтому установка и ежедневная работа не должны требовать запуска двух программ, ручного ввода ключей или настройки Node.js.

## Решение

Выпускается третий продукт `Термбург Рабочее место`. Он переиспользует существующий desktop-entry расписания и подключает Dolphin как встроенный фоновый runtime. Отдельные сборки расписания и Dolphin сохраняются.

Объединённая программа:

- переносит существующее расписание и локальные настройки, не перезаписывая новые данные;
- переносит защищённую активацию отдельного Dolphin, когда она доступна;
- запускает проверку Dolphin сразу и затем каждые пять минут;
- регистрирует один автозапуск Windows и при автозапуске остаётся в трее;
- показывает состояние и ручную проверку Dolphin в меню;
- использует одноразовую zero-config активацию, секрет которой не хранится в Git.

## Отклонённые варианты

- Запускать второй EXE дочерним процессом: сложнее обновлять, диагностировать и корректно завершать; сотруднику всё равно приходится устанавливать два продукта.
- Скопировать весь код расписания в новый entry: будущие исправления расходились бы между двумя версиями.
- Встроить серверный API-ключ в приложение: секрет можно извлечь из публичной сборки; вместо этого остаётся обмен одноразовой активации на защищённый device token.

## Последствия

- У объединённой сборки отдельные app id и папка данных.
- После проверки старые отдельные приложения необходимо убрать из автозапуска, чтобы не было параллельных проверок.
- Один установщик активирует один новый компьютер. Следующая установка требует новой сборки и нового серверного хеша.
- Автоматическое погашение включается серверной настройкой после подтверждения схемы локального API; установщик менять для этого не требуется.

## Проверка и откат

- Gate: тесты расписания, Dolphin и миграции проходят без ошибок.
- Gate: упакованный EXE поднимает расписание на временном порту и содержит оба ресурса Dolphin, не расходуя активацию.
- Откат: удалить объединённую программу и продолжить использовать две отдельные сборки; исходные папки их данных не изменяются.
