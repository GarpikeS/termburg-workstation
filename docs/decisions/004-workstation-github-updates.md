# 004. Отдельный канал обновлений Workstation

## Решение

Workstation проверяет релизы публичного репозитория `GarpikeS/termburg-workstation` и предлагает установить более новую стабильную версию.

## Контракт релиза

- тег: `workstation-vX.Y.Z`;
- установщик обновления: `Termburg-Workstation-Update-X.Y.Z.exe`;
- контрольная сумма: `Termburg-Workstation-Update-X.Y.Z.exe.sha256`;
- черновики и prerelease игнорируются;
- установка начинается только после подтверждения пользователя;
- скачанный файл принимается только при совпадении SHA-256.

## Граница безопасности

Публичный релиз предназначен только для обновления уже активированной Workstation и не содержит одноразовый enrollment-token Dolphin. Первичный установщик с токеном публикуется отдельно на сервере `tbgame.ru`. Сохранённые расписание, настройки сайта и зашифрованный Windows-ключ Dolphin лежат вне каталога приложения и переживают обновление.

## Совместимость

Версия `1.0.0` ещё не содержит обновлятор, поэтому переход на первую версию нового канала выполняется вручную. Все последующие стабильные версии обнаруживаются приложением автоматически.
