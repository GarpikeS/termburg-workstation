# ADR 006: установщик Workstation с полномочиями одного комплекса

## Статус

Принято для версии Workstation `1.1.14`.

## Решение

- Первичный Setup выпускается отдельно для каждого комплекса.
- Пакет содержит один device profile, один site-sync token, один локальный account verifier и один одноразовый Dolphin enrollment-token.
- Публичное обновление не содержит ни одного из этих установочных секретов.
- Setup передаётся напрямую по закрытому каналу и не публикуется в GitHub или статическом каталоге сайта.
- Перед сборкой и после неё `workstation/generated` удаляется, а пакет собирается из чистого commit/worktree.
- Packaged smoke-test проверяет точный профиль, точный список site-sync location IDs, точный список локальных аккаунтов и наличие либо отсутствие enrollment-token.

## Причины

ASAR — упаковка, а не шифрование. Любые встроенные значения можно извлечь из EXE, поэтому установщик должен иметь минимальные полномочия и ограниченную раздачу. Обновление устанавливается на уже настроенную машину и не нуждается в повторной передаче секретов.

## Последствия

Один Setup активирует один новый компьютер. Перед его первым запуском на сервере меняется только `DOLPHIN_ENROLLMENT_TOKEN_HASH`; существующие device tokens продолжают работать из `dolphin-connectors.json`.
