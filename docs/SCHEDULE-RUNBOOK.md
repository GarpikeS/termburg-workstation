# Расписание Термбурга: запуск и работа

## Быстрый запуск

1. Скопируйте последнюю версию `Termburg-Schedule-*-portable.exe` на основной компьютер.
2. Дважды нажмите EXE — откроется отдельное окно «Термбург Расписание».
3. Не закрывайте это окно: пока приложение запущено, телевизоры и мобильный раздел получают обновления.
4. Если Windows покажет SmartScreen, проверьте имя файла и его контрольную сумму, затем выберите «Подробнее» → «Выполнить в любом случае».

EXE не требует установки Node.js и не удаляет раздел расписания из игры. Файл не подписан коммерческим сертификатом, поэтому предупреждение SmartScreen на новом компьютере возможно. Если Windows спросит о доступе через брандмауэр, разрешите доступ только для частных сетей.

`start-schedule.cmd` сохранён как резервный способ запуска для разработчика из исходного проекта.

## Адреса

В редакторе показан готовый адрес «Адрес для телевизора» и кнопка «Копировать». Вместо `<IP-компьютера>` в примерах ниже используется адрес основного компьютера, например `192.168.1.25`.

- Редактор: `http://<IP-компьютера>:4174/schedule/admin`
- ТВ, комплекс №1: `http://<IP-компьютера>:4174/schedule/screen/1`
- ТВ, комплекс №2: `http://<IP-компьютера>:4174/schedule/screen/2`
- Печать/PDF: `http://<IP-компьютера>:4174/schedule/print/1`
- Мобильный раздел: `http://<IP-компьютера>:4174/bathhouses/1/schedule`
- Проверка сервера: `http://<IP-компьютера>:4174/api/health`

На каждом ТВ откройте его адрес в полноэкранном режиме. ТВ-экран автоматически перестраивается под горизонтальную или вертикальную ориентацию. Экран перечитывает расписание каждые 5 секунд; мобильная версия — каждые 15 секунд. Текущее событие и следующее событие меняются автоматически без перезагрузки страницы.

## Работа редактора

1. Выберите комплекс.
2. В разделе «Обычная неделя» настройте повторяющиеся события и дни недели.
3. В разделе «Особые даты» добавляйте праздники и разовые события.
4. Проверьте платность, цену, место и переключатель «Опубликовано».
5. Нажмите «Сохранить и показать всем».

## Отправка расписания на сайт

1. В редакторе раскройте блок «Синхронизация с сайтом».
2. Для Зеленогорска оставьте адрес `https://termburg45.ru/wp-json/termburg/v1/schedule/import`.
3. Выберите `Authorization: Bearer`.
4. Оставьте проверочный код комплекса `zelenogorsk`.
5. Вставьте токен и нажмите «Сохранить подключение». Токен хранится только на компьютере редактора в файле `site-sync.json` и не передаётся на телевизоры.
6. Сначала сохраните изменения расписания, затем нажмите «Отправить расписание на сайт».

Приложение отправляет полный массив опубликованных событий выбранного комплекса методом `PUT`. Каждая успешная отправка заменяет расписание на сайте. Если сайт недоступен или отклоняет запрос, локальное расписание и телевизоры продолжают работать; редактор показывает причину ошибки.

Ответ считается успешным только при `success: true`, `site: "zelenogorsk"` и полном совпадении `count` с количеством отправленных событий. URL Москвы в программу не предустановлен, чтобы исключить ошибочную отправку московского расписания на сайт Зеленогорска.

В форме события переключатель «Выделить на сайте» управляет полем `highlight` независимо от цены. В разделе «Особые даты» переключатель «Санитарный день» создаёт служебную запись `type: closed` и скрывает обычную программу этой даты.

Кнопка «JSON-копия» скачивает резервную копию. В EXE рабочие данные хранятся независимо от самого исполняемого файла:

`%APPDATA%\Термбург Расписание\schedule.json`

EXE можно заменить новой версией или перенести в другую папку — расписание останется на компьютере. Не удаляйте папку данных без резервной JSON-копии.

## Печать

В печатной студии выберите день, неделю или месяц, затем книжную или альбомную ориентацию. Кнопка «Печать / PDF» открывает системный диалог: в нём можно выбрать принтер или «Сохранить как PDF».

## Защита редактора и закрытие

В desktop-версии изменять расписание разрешено только из локального окна редактора. Устройства в общей сети могут читать расписание, но не могут сохранить изменения. При закрытии окна приложение завершает сервер и освобождает порт `4174`.

Для резервного запуска из исходников можно дополнительно задать ключ:

```powershell
$env:SCHEDULE_ADMIN_TOKEN = 'длинный-случайный-ключ'
npm run schedule:start
```

Тот же ключ введите в поле «Ключ редактора». Публичные экраны ключ не используют и сохранять расписание не могут.

Если EXE сообщает, что порт `4174` занят, закройте ранее запущенное расписание или `start-schedule.cmd`, затем повторите запуск.

## Подключение сайта

Сайт может читать тот же JSON через `GET http://<IP-компьютера>:4174/api/schedule`. Для публичного сайта лучше перенести этот неизменный контракт в облачный backend и задать приложению `VITE_SCHEDULE_API_URL` на этапе сборки. Интеграция с CRM «Дельфин» в MVP намеренно не используется.

## Важно перед вводом в работу

Встроенное расписание заполнено демонстрационными данными по присланным примерам. Перед показом гостям замените его на утверждённое актуальное расписание обоих комплексов и сделайте JSON-копию.
